## 実行環境

- macOS 14、Node.js 24.19.0、pnpm 11.19.0。
- Cloudflare Vite pluginのローカルworkerdとSQLite Durable Objects。`pnpm build`後に`pnpm preview --port 5173`で起動。
- ChromiumはリポジトリのPlaywright 1.63.0を使用。
- 同バージョン付属のWebKitは、このmacOSでは`Unknown setting: PushAPIEnabled`で起動できなかった。独立した一時ディレクトリでPlaywright 1.55.1とWebKit 26.0を用い、**同一のテストファイル15件**を同じ本番ビルドに対して実行した。プロジェクトの依存関係は変更していない。
- GitHub ActionsにはUbuntuでリポジトリのPlaywrightを使うChromium・WebKit両方の検証を設定済み。リモートCIはまだ実行していない。

`pnpm test:e2e`は本番ビルドを作成し、5173番ポートでプレビューを起動する。既存サーバーを再利用する設定のため、検証前に`pnpm dev`を終了し、テスト対象が本番ビルドになるようにする。
